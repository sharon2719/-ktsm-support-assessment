## My approach

I wrote each document for the person who will read it:
- **Service Manager:** a short, plain update.
- **Next engineer:** a clear list of what is done and what is still open.
- **Support and development teams:** what happened and how to stop it happening again.
- **Service Desk:** simple steps and clear rules for when to escalate.

I only used facts from the logs and the brief. I did not guess times that were not given. The logs do not say which locker is at Westlands mall, so the site of each locker is marked as still to be confirmed.
