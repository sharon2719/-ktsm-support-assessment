# Knowledge Base: Locker Door Will Not Open

**For:** Service Desk (L1)
**Use this when:** a customer says a locker door will not open.

> **Note:** "Admin portal" means the locker system the Service Desk uses. Replace it with the real tool name.

## Step 1: Get the details

Ask the customer for:
1. The site name or locker location
2. The locker ID (shown on the locker screen)
3. The compartment number, if they have it
4. Their collection code or tracking number
5. The time it happened
6. What happened: an error message, nothing happened, or the door clicked but did not open

Write all of this in the ticket.

## Step 2: Check the collection code

1. Check the code is correct.
2. Check the code has not expired.
3. Check the code is for the right parcel and the right locker.
4. **Only if the code is wrong or expired**, send a new code.
5. Ask the customer to try **one more time**.

Still not working? Go to Step 3.

## Step 3: Check the locker in the admin portal

1. Search for the locker ID.
2. Check if the locker is **online** or **offline**.
3. Check for any errors or alerts.

- **Locker is offline:** write it in the ticket, send the ticket to the field support team, and tell the customer we are working on it.
- **Locker is online:** go to Step 4.

## Step 4: Try to open the door remotely

Use the admin portal to open the door.

- **Door opens:** the customer collects the parcel. Update and close the ticket.
- **System shows an error:** write down the exact error and escalate to L2.
- **Door clicks but stays stuck:** this may be a physical problem. Send the ticket to field support.

**Do not keep trying** if the system shows an error. Try once, write down the error, and escalate.

## Step 5: Check if others are affected

Look for:
- Other customers with the same problem
- Other lockers at the same site with problems
- Similar tickets from other sites
- A software update or maintenance that happened just before

Add any related ticket numbers to your ticket.

## When to escalate to L2

Escalate to L2 if **any** of these are true:
- The locker is online, but the remote open fails.
- More than one customer has the same problem.
- More than one locker has the same problem.
- Several sites have the same problem.
- The problem started after a software update or maintenance.
- You see an error you do not know.
- The problem continues after Steps 1 to 4.

**Priority:** use the company's incident priority rules. If a whole site or several sites are affected, treat it as urgent.

## When to send to field support

Send the ticket to field support if:
- The locker is offline.
- The door clicks but does not open.
- The door looks jammed or damaged.

If it could be both a software and a physical problem, contact both L2 and field support.

## What to put in the escalation ticket

- Locker ID and site
- Compartment number
- Number of customers affected, if known
- Time of the first report
- The exact error message or a screenshot
- What you have already tried
- Any related tickets or recent updates

## What to tell the customer

1. Give them the ticket number.
2. Tell them we are working on it.
3. Tell them when to expect the next update.

Do not promise a fix time unless it has been confirmed.
